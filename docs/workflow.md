# 工作流与数据流

## 正常用户流程

1. 用户打开GitHub Pages在线版或离线版工具。
2. 用户在「AI 生成」中填写PPT主题、受众、时长、页数、语言、用途和视觉方向，并可上传或粘贴本地材料。
3. 工具在本地读取材料并生成一份完整LorealGPT提示词；用户主动点击「复制提示词」。
4. 用户在公司批准的LorealGPT中粘贴一次提示词。LorealGPT在同一次回答中完成内容分析、页面蓝图、图表/视觉规划，并为需要自由表达的页面同时生成完整静态HTML。
5. 用户把完整回答（或其中的HTML）粘贴回工具，或从本地导入HTML文件。工具提取页面并在隔离环境中显示缩略图和可视化编辑画布。
6. 用户修改文字、字体、字号、颜色、背景、图片、模块位置和尺寸；工具只在本地更新。
7. 工具运行本地质量检查并提示溢出、越界、小字号、缺图、低对比度和重复页面。
8. 用户导出自包含HTML、图片型PPTX或本地项目文件（默认 `.pptdlab`；打开项目兼容旧版 `.pptdlab.json` / `.json`）。

### 首版材料入口

材料读取使用浏览器本地能力，不上传文件：

- 文本、Markdown、CSV、TSV、JSON、HTML、XML：直接读取文本内容。
- PDF：首版提取可复制的文字层；扫描件不做OCR。
- Word：首版支持 `.docx` 的基础文字提取，不支持旧 `.doc`。
- Excel：首版支持 `.xlsx`、`.xls` 的工作表单元格值提取，不理解宏、图表或复杂公式语义。
- 解析失败时，用户仍可把材料摘要直接粘贴到需求表单；原文件不会离开本机。

### 首页三页内置演示

首次打开工具会载入三页无业务数据的通用示例，帮助用户快速上手：

1. 「工具是什么、适合谁」：解释无需安装、手工复制LorealGPT、本地编辑导出和运营/战略/项目等场景。
2. 「一条清晰的本地工作流」：展示填写需求 → 复制完整提示词 → 粘贴返回HTML → 编辑、保存、导出的四个动作，以及本地隐私路径。
3. 「高级视觉生成系统」：展示咨询蓝、黑金、暖米三套视觉系统，10种页面结构、25+模块四大分组、页面蓝图字段和自由HTML路径。

## 字号与版式生成规则

- 1920×1080 画布使用 CSS px，约 `2px ≈ 1pt`；字号按信息密度和文本角色设置，不按同一倍率全局放大。
- 标准档：封面主标题 84–96px、普通页标题 58–68px、副标题/强调 40–48px、正文 30–36px、注释/页脚 24–28px、标签/表格 22–24px。稀疏页可适度放大；密集页正文可用 28–32px，一般不低于 22px。
- 生成 HTML 前和输出前都检查元素重叠、内容裁切、越界、意外换行、标题/标签重叠、卡片高度和文字基线。字号变大时同步扩容容器、增高卡片、调整换行或重新分栏。
- 双栏布局必须显式设置左右列，至少保留 80px gutter；圆形主视觉、投票框或大图固定在所属列内，不能通过水平居中挤压右栏文字。
- 重复卡片、三栏信息和时间线统一内边距、图标/标记列宽、文字起始坐标和行高；发现问题优先修正容器和分栏，不要继续放大字号。

## 结构化HTML约定

- 画布：1920×1080，16:9。
- 每页：一个直接、独立的 `<section class="slide" data-slide-id="..." data-screen-label="...">`。
- 正文：静态HTML；可编辑文字分别放在叶子元素中。
- 样式：使用CSS变量统一管理字体、字号、颜色、间距和安全边距。
- 内容：不使用React/Vue或脚本循环生成可编辑正文。
- 网络：不依赖外部脚本、字体、iframe或运行时API。
- 图片：导入后优先内嵌或由用户保存在本地项目文件中。

## PPTX导出策略

### 默认：图片型PPTX

- 每个HTML幻灯片在浏览器中以固定尺寸渲染为高清图片。
- 每张图片作为一页全幅内容写入PPTX。
- 优先保证视觉一致性，不承诺对象级编辑。

### 后续：基础可编辑PPTX

- 普通文字、图片和简单色块映射为PowerPoint原生对象。
- 复杂CSS、SVG、Canvas、图表与特殊效果按元素或整页回退为图片。
- 可编辑性不得以破坏版式或泄露内容为代价。

## 数据边界

| 数据 | 所在位置 | 是否进入GitHub |
|---|---|---|
| 工具源码、通用模板、许可证 | 项目根与GitHub仓库 | 是 |
| 用户填写的PPT要求 | 浏览器内存；用户主动保存时进入本机项目文件 | 否 |
| LorealGPT提示词和回答 | 公司LorealGPT会话与用户剪贴板 | 否 |
| 导入的HTML、图片、品牌模板 | 公司电脑本地 | 否 |
| 导出的HTML、PPTX、`.pptdlab` 项目文件 | 公司电脑本地下载目录 | 否 |

## 发布流程

1. 运行项目审计和产品测试。
2. 确认发布包不包含公司内容、测试业务数据或凭据。
3. 发布纯静态工具到GitHub Pages。
4. 同时生成离线ZIP。
5. 在公司电脑验证访问、导入、编辑与导出，并检查网络记录。
