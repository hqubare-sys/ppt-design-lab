# v0.1 技术规格与界面信息架构

## 1. 产品定位

PPT Design Lab 是一个纯静态、本地优先的浏览器工具。它不直接调用 LorealGPT，也不上传用户的 PPT 内容。用户在工具中生成提示词，在公司批准的 LorealGPT 中手工生成结构化 HTML，再把结果粘贴回工具完成可视化修改和本地导出。

v0.1 只服务固定尺寸的 HTML 幻灯片，不承担任意网页的无损编辑或转换。

## 1.1 视觉生成系统

工具不把页面锁死为几套整页模板，而是提供可复用的视觉约束，供LorealGPT在一次完整生成中自由组合：

- 三套视觉系统：咨询蓝、黑金、暖米。每套系统定义背景、主辅色、字体层级、圆角、边框、阴影、图表和图片处理方式。
- 十种页面结构原型：核心结论、主分析＋辅助证据、数据仪表盘、趋势＋原因、对比与选择、矩阵与组合、流程与方法、路线图与时间线、问题—原因—行动、总结与决策。
- 第一批二十五个以上视觉模块，分为数据分析、逻辑表达、项目管理、叙事与品牌四组；代表模块包括KPI、趋势图、排名表、矩阵、问题树、因果链、流程图、风险矩阵、时间线、路线图、里程碑、行动计划、图片卡和结论条。
- 页面蓝图字段至少包含 `page_goal`、`key_message`、`structure`、`modules`、`data`、`copy`、`visual_style`。LorealGPT可以根据蓝图同时返回自由HTML；工具继续使用安全导入器载入并编辑。

这套系统是“可复用的设计语言”，不是强制的固定模板：内容和数据决定页面结构，主题和模块帮助不同页面保持高级感与一致性。

## 2. 技术边界

- 运行形态：静态 HTML、CSS、JavaScript；不需要后端。
- 公司电脑：只需要现代 Chrome 或 Edge，不安装 Node.js、Python、LibreOffice、扩展或桌面应用。
- 开发形态：原生 JavaScript，避免构建工具成为运行依赖。
- 发布形态：GitHub Pages 在线版 + 离线 ZIP；全部第三方依赖存放于 `app/vendor/`。
- 网络边界：工具初始加载后，核心流程不产生任何外部请求。
- 存储边界：默认只保存在内存；显式保存生成本地项目文件。IndexedDB 自动保存延后到用户确认后再启用。

## 3. 结构化幻灯片契约

LorealGPT 返回一个完整 HTML 文档，其中每页满足：

```html
<main class="deck" data-deck>
  <section class="slide" data-slide-id="slide-01" data-screen-label="01">
    <div class="slide-content">
      <h1>页面标题</h1>
      <p>页面正文</p>
    </div>
  </section>
</main>
```

约束：

- 画布固定 1920×1080，16:9。
- `.slide` 或 `[data-slide]` 表示一页；兼容 `deck-stage > section`。
- 正文使用静态 HTML，重复结构必须直接展开。
- 每段可编辑文字放在独立叶子元素中。
- CSS 使用变量管理字号、颜色、间距和安全边距。
- 不使用 React、Vue、运行时循环、iframe、表单提交或远程 API。
- 图片优先使用占位符，导入后由用户选择本地文件替换并内嵌。
- 复杂 Canvas 与脚本图表不属于 v0.1 可编辑范围。

## 4. 安全导入

HTML 进入编辑器前通过 `DOMParser` 解析，并执行以下本地处理：

1. 删除 `script`、`iframe`、`object`、`embed`、`base`、`form`、`meta[http-equiv=refresh]`。
2. 删除所有 `on*` 事件属性和 `javascript:` URL。
3. 删除外部 stylesheet、preload、modulepreload 和字体链接。
4. 删除 CSS `@import` 及指向 `http:`、`https:`、协议相对地址的 `url(...)`。
5. 将外部图片替换成明确的本地占位符；不主动下载远程图片。
6. 只保留结构化幻灯片及其静态样式。
7. 对处理结果给出警告摘要，不静默执行活动内容。

编辑与预览使用 `iframe srcdoc`。iframe 不允许页面脚本运行；父页面只对已经净化的 DOM 绑定编辑事件。

## 5. 应用界面

### 顶部工具栏

- 新建
- AI 生成
- 粘贴 HTML
- 打开 HTML
- 保存项目
- 导出 HTML
- 导出 PPTX
- 隐私状态：`仅本机处理`

### 左侧幻灯片栏

- 页面缩略图和页码
- 点击切换页面
- 新增、复制、删除页面
- 上移、下移页面；拖拽排序延后到后续迭代
- 当前页与存在问题的页面有明确状态

### 中央编辑区

- 固定 1920×1080 画布按窗口自动缩放并留黑边/灰边
- 单击选择元素，双击进入文字编辑
- 选择框和尺寸信息
- 拖动普通模块改变位置；第一次拖动流式元素时提示会切换为绝对定位
- 使用方向键微调；Shift + 方向键大步移动
- 画布外不显示幻灯片内容

### 右侧属性栏

- 文字：内容、字体、字号、字重、行高、颜色、对齐
- 外观：背景、边框、圆角、透明度
- 布局：X、Y、宽、高、层级、对齐到页面
- 图片：选择本地文件替换、适应/裁切、替代文字
- 页面：背景色、页面名称、复制、删除

### AI 生成窗口

- 表单：主题、受众、时长、页数、语言、用途、风格、材料
- 第一步：工具本地读取材料，并生成一份包含内容分析、页面蓝图、视觉系统、模块选择和自由HTML要求的完整提示词；用户点击「复制提示词」
- 第二步：用户在公司批准的LorealGPT中粘贴一次提示词；LorealGPT完成内容规划，并在同一次回答中生成完整HTML（需要特殊表达的页面也直接返回自由HTML）
- 第三步：用户粘贴LorealGPT回答或HTML，工具提取页面、净化并载入编辑器
- 失败时生成可复制的修复提示词；工具不自动调用LorealGPT

### 本地材料解析

所有材料先由浏览器本地读取，再作为用户主动复制到LorealGPT的提示词内容；原文件不上传：

- 文本、Markdown、CSV、TSV、JSON、HTML、XML：读取文本。
- PDF：仅提取可复制的文字层，不做扫描件OCR。
- Word：仅支持`.docx`基础文字提取，不支持旧`.doc`。
- Excel：支持`.xlsx`、`.xls`读取工作表单元格值，不解析宏、图表或复杂公式语义。
- 解析失败可改为粘贴材料摘要；错误信息不包含文件内容外传路径。

## 6. 状态模型

```text
Project
├── metadata: title, createdAt, updatedAt, version
├── headHtml: 安全的 meta/title/style
├── css: 已净化的全局样式
├── slides[]
│   ├── id
│   ├── label
│   └── html
└── warnings[]
```

- 当前编辑页由 iframe DOM 表示。
- 每次切页、保存或导出前，将 iframe DOM 同步回 `slides[]`。
- 撤销/恢复使用有限长度的项目快照历史，v0.1 上限 40 次。
- 项目文件扩展名使用 `.pptdlab`，只由用户主动下载和重新打开；打开项目兼容旧版 `.pptdlab.json` / `.json`。

## 7. 导出

### 自包含 HTML

- 合并安全 head、CSS 和全部幻灯片。
- 注入工具自有的本地播放壳：缩放、键盘导航、页码和全屏。
- 不包含编辑器界面、远程依赖或用户机器路径。

### 图片型 PPTX

- 逐页以 1920×1080 渲染为 PNG。
- 每页在无脚本、`sandbox="allow-same-origin"` 的离屏 `iframe srcdoc` 中渲染，CSS 与编辑预览处于相同的文档根环境，避免 Shadow DOM 使 `:root` 主题变量失效。
- PNG 底色取幻灯片根、body、html 的实际计算背景色，不用固定白色覆盖页面主题；CSS 渐变仍由原页面绘制。
- 对浏览器中原本为单行、且不含显式换行的叶子文字加入仅导出时的单行稳定样式，减少字体度量差异造成的尾字换行。
- 每张 PNG 全幅放入一页 16:9 PPTX。
- 图片生成与 PPTX 打包均在浏览器内完成。
- 对远程图片、字体缺失和渲染失败给出明确提示。
- v0.1 不承诺原生对象可编辑；基础可编辑 PPTX 属于后续增强。

## 8. 质量检查

本地检查至少覆盖：

- 幻灯片内容越界。
- 正文字号低于 24px；标题字号低于 40px。
- 图片加载失败或仍为外部地址。
- 文本与背景的基础对比度不足。
- 空白页面、重复页面和缺失页面标识。
- 元素尺寸为零或完全位于页面外。

## 10. v0.1 原型验收切片

第一轮原型必须真实完成：

1. 内置非敏感三页演示 deck 可直接载入：工具定位与适用场景、本地四步工作流、高级视觉生成系统示意图。
2. AI 提示词表单可读取首版材料格式、生成并复制一份完整提示词；LorealGPT一次返回页面蓝图和自由HTML。
3. 粘贴结构化 HTML 后完成净化、分页和警告显示。
4. 可切页、编辑文字、修改字体与字号、拖动和调整普通模块尺寸、替换本地图片。
5. 可新增、复制、删除、上移和下移页面。
6. 可撤销、恢复并保存/打开 `.pptdlab`（兼容旧版 `.pptdlab.json` / `.json`）。
7. 可导出自包含 HTML。
8. 图片型 PPTX 导出入口存在；若浏览器依赖尚未打包，必须明确标为未完成，不能伪装成功。
9. 没有后端、遥测和内容外传路径。
